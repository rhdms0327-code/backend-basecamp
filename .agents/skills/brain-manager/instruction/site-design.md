# 🎨 사이트 디자인 공통 규칙 (Site Design)

> 기준 화면: `홈 › .NET › C# 10`. 새 카테고리·주제·글을 만들 때 이 규칙을 따라 모든 주제가 같은 모양으로 보이게 한다.
> 사이트는 `scripts/build-site.mjs`가 `docs/`를 읽어 만든다. 아래 규칙은 그 빌드가 실제로 읽는 방식에 맞춘 것이다.

---

## 1. 폴더 계층: 2단계만

| 단계 | 경로 | 화면 |
| :--- | :--- | :--- |
| 카테고리 | `docs/NN-영문이름/index.md` | 왼쪽 메뉴의 1단 (예: .NET, English) |
| 주제 | `docs/NN-영문이름/주제/index.md` | 왼쪽 메뉴의 2단, 글 목록 페이지 (예: C# 10, 오픽) |
| 글 | `docs/NN-영문이름/주제/docs/파일.md` | 글 읽기 페이지 |

- **3단계 폴더 금지**: `주제/하위폴더/index.md`는 빌드가 무시하고, 그 안의 글은 상위 주제에 섞여 보인다.
- 주제 안을 나누고 싶으면 폴더가 아니라 **제목 접두어(2번)** 와 **인덱스 소제목(3번)** 으로 나눈다.
- 파일명은 영문 kebab-case (`garbage-collection.md`). 날짜 기록은 `YYYYMMDD.md`.

---

## 2. 글 제목: `이모지 [그룹] 제목`

```yaml
title: "🎯 [7장] 클래스 및 멤버 개요 (Class & Members)"
```

| 요소 | 규칙 | 화면 |
| :--- | :--- | :--- |
| 이모지 | 주제마다 1개로 고정 (C# 10 = 🎯, 오픽 = 🗣️) | 화면에서는 자동으로 지워진다 |
| `[그룹]` | 같은 주제 안의 묶음 이름. 장 번호, 분석 시리즈, 회차 등 | 오른쪽 "이 주제의 순서"에서 **칩**으로 바뀐다. 글 목록에서는 제목 글자 그대로 보인다 |
| 제목 | 그룹 이름을 다시 쓰지 않는다 | `[오픽] 오픽 시험 구조` ✗ → `[오픽] 시험 구조 파악` ✓ |

- **그룹 라벨은 이 접두어 하나로만 표시한다.** 태그, 별도 배지, 색으로 그룹을 표시하지 않는다.
- 그룹 이름은 짧게(10자 안팎). 길면 순서 목록에서 제목이 밀린다.
- 그룹이 필요 없는 글은 접두어 없이 쓴다 (예: `🎯 레코드 (record)`).

---

## 3. 주제 index.md: 소제목으로 묶은 표

```markdown
## 📂 리스트 (총 N건)

### 🚀 들어가며: .NET 개요와 환경 설정

| 제목 | 키워드 |
| :--- | :--- |
| **[🎯 [.NET 분석] .NET이란 무엇인가?](./docs/what-is-dotnet.md)** |  |
```

- 표에 적은 **링크 순서 = 학습 순서**. 빌드가 이 순서로 "이 주제의 순서"와 이전/다음 글을 만든다.
- 그룹이 여러 개면 `### 이모지 소제목`마다 표를 하나씩 둔다. 소제목과 제목 접두어는 같은 묶음을 가리키게 맞춘다.
- 표 앞뒤 빈 줄, `| :--- |` 구분선 규칙은 `main-index.md`를 따른다.

---

## 4. 태그 = 키워드 (화면 라벨 아님)

- `tags`는 검색·분류용 **키워드**다. 사이트 화면에 배지로 표시하지 않는다.
- 같은 값을 인덱스 표의 **키워드 칸**에 백틱으로 적는다 (`` `메모리` `객체지향` ``).
- 사용자가 요청하기 전에는 미리 쓰지 않는다 (`main-index.md` 3번).

---

## 5. 배지와 색: 사이트가 자동으로 붙인다

| 위치 | 표시 | 문서에서 할 일 |
| :--- | :--- | :--- |
| 글 목록 오른쪽 | 주제 배지 1개 (카테고리 색) | 없음 |
| 오른쪽 순서 목록 | 번호, 읽음(✓), `[그룹]` 칩 | 제목 접두어만 지킨다 |
| 글 상단 | 작성일, 읽는 시간 | `date`를 넣는다 |

- 문서나 사이트 코드에 배지·색을 따로 추가하지 않는다. 구분이 더 필요하면 먼저 2번(접두어)과 3번(소제목)으로 해결한다.

---

## 6. 체크리스트

- [ ] 폴더가 `카테고리/주제/docs/` 2단계인가
- [ ] 제목이 `이모지 [그룹] 제목` 형식이고, 이모지가 주제 안에서 같은가
- [ ] 제목 본문이 그룹 이름을 반복하지 않는가
- [ ] 인덱스 표 순서가 읽는 순서와 같은가
- [ ] 태그를 그룹 표시 용도로 쓰지 않았는가
