> 코딩테스트는 프로그래머스 한 곳에서 C#으로 준비합니다. 고득점 Kit 중 C#으로 제출할 수 있는 37문제를 뼈대로 두고, 같은 유형의 Lv.2 문제로 보강해 0~6단계로 진행합니다. 목표는 Lv.2를 40분 안에 안정적으로 푸는 것입니다.

---

## 왜 프로그래머스인가

- **시험 형식이 같다**: 국내 기업 코테는 함수만 작성하는 프로그래머스 형식이 많아, 연습이 곧 실전 대비가 됩니다.
- **C# 부담이 적다**: 입력을 직접 파싱하지 않아도 되어 로직에만 집중할 수 있습니다.
- **유형별로 정리돼 있다**: 고득점 Kit가 자주 나오는 유형 10개로 묶여 있어 단계 구성과 그대로 맞습니다.
- **분량이 충분하다**: C#으로 풀 수 있는 문제가 Lv.1 72 · Lv.2 88 · Lv.3 56개입니다 (2026-10-14 기준).

문제 수가 백준보다 적은 것이 단점이지만, Lv.2~3 중심 목표에는 충분합니다. 특정 유형이 부족할 때만 다른 사이트로 보강합니다.

---

## 풀이 원칙

1. **30분**: 혼자 고민하고, 막히면 풀이를 봅니다. 풀이를 본 문제는 '다시 풀기'로 표시합니다.
2. **3줄 노트**: 풀고 나면 유형 · 핵심 아이디어 · 실수한 부분을 적습니다.
3. **3일 · 7일**: '다시 풀기' 문제는 3일, 7일 뒤에 처음부터 다시 풉니다.
4. **40분**: 4단계부터는 타이머를 켜고 Lv.2를 40분 안에 푸는 것을 기준으로 삼습니다.
