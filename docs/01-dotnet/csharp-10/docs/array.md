# 🧠 [10장] 배열 (Array)

> 동일한 타입의 데이터 요소들을 연속된 메모리 공간에 저장하는 C#의 가장 기본적인 자료구조인 배열의 특징과 선언 방법을 정리합니다.

## 📖 1. 개요
- 동일한 타입의 데이터 요소들이 **연속된 메모리 공간**에 저장된 자료구조입니다.
- 가장 기본적이고 원시적인 형태의 컬렉션입니다.

## 🏗️ 2. 주요 특징
- **동일 타입**: 모든 요소의 데이터 타입이 같아야 합니다.
- **고정 크기**: 선언 시 결정된 크기를 실행 중에 변경할 수 없습니다.
- **인덱스 접근**: 0부터 시작하는 인덱스를 사용하여 데이터에 매우 빠르게 접근할 수 있습니다.

> [!TIP]
> 배열은 고정 크기 자료구조이므로, 크기가 유동적으로 변해야 하는 상황에서는 `List<T>`와 같은 동적 컬렉션 사용을 고려하는 것이 좋습니다.

## 🎯 3. 선언 및 초기화

```csharp
// 선언과 동시에 크기 지정
int[] scores = new int[5];

// 선언과 동시에 초기화
int[] numbers = new int[] { 1, 2, 3, 4, 5 };

// 더 간결한 초기화
string[] names = { "Kim", "Lee", "Park" };
```

### 3.1 `new[] { ... }`: 타입을 생략한 배열 생성

`new[] { "a = 4", "b = 5" }`는 "문자열 두 개가 들어 있는 배열을 지금 만든다"는 뜻입니다.

```csharp
new   []   { "a = 4", "b = 5" }
 ①    ②          ③
```

| 조각 | 뜻 |
| :--- | :--- |
| ① `new` | 새로 만든다 |
| ② `[]` | 만드는 것이 **배열**이다. 대괄호 안에 크기를 안 쓰면 ③의 개수로 정해진다 |
| ③ `{ ... }` | 배열에 처음부터 넣을 값들 (초기값 목록) |

타입을 적지 않아도 컴파일러가 ③의 값을 보고 타입을 정합니다. 값이 모두 문자열이면 `string[]`, 모두 정수면 `int[]`입니다.

#### 같은 뜻의 네 가지 표기

위에서 아래로 갈수록 생략한 것이 많아집니다. 만들어지는 배열은 모두 같습니다.

```csharp
string[] a = new string[2] { "a = 4", "b = 5" };  // 타입, 크기, 값을 모두 적음
string[] b = new string[]  { "a = 4", "b = 5" };  // 크기 생략 → 값 개수로
string[] c = new[]         { "a = 4", "b = 5" };  // 타입도 생략 → 값으로 추론
string[] d =               { "a = 4", "b = 5" };  // new까지 생략 (변수 선언할 때만 가능)
```

`d`처럼 `new`를 생략한 형태는 **변수를 선언하는 자리에서만** 쓸 수 있습니다. 메서드나 애트리뷰트에 인수로 바로 넘길 때는 `new[] { ... }`처럼 `new`가 있어야 합니다.

#### 값의 타입이 섞이면 오류

```csharp
new[] { "a", "b" }   // string[]
new[] { 1, 2 }       // int[]
new[] { 1, "a" }     // 컴파일 오류: 공통 타입을 정할 수 없음
```

> [!TIP]
> `var`와 함께 쓰면 `var a = new[] { 0, 1, 2 };`처럼 왼쪽과 오른쪽 모두 타입을 생략할 수 있습니다. 이때 `a`는 `int[]`입니다.

## 🧱 4. 다차원 및 가변 배열

### 4.1 2차원 배열 (int[,])
`int[,]`은 행(Row)과 열(Column)로 이루어진 격자(Grid) 형태의 데이터를 다룰 때 사용하는 2차원 배열 문법입니다. 대괄호 안의 콤마(`,`) 개수가 차원의 수를 나타내며, 콤마가 두 개(`int[,,]`)이면 3차원 배열이 됩니다.

**선언 및 초기화**

```csharp
// 크기가 3행 4열인 2차원 배열 선언 및 생성
int[,] matrix = new int[3, 4];

// 선언과 동시에 값 초기화 (2행 3열)
int[,] grid = new int[,] {
    { 1, 2, 3 },
    { 4, 5, 6 }
};

// 'new int[,]'는 생략 가능
int[,] grid2 = {
    { 1, 2, 3 },
    { 4, 5, 6 }
};
```

**접근 방식**

각 요소는 `[행, 열]`처럼 행 인덱스와 열 인덱스를 콤마로 구분하여 접근합니다. 인덱스는 모두 0부터 시작합니다.

```csharp
int[,] board = new int[3, 3];

// 값 대입
board[0, 1] = 10;

// 값 읽기
int value = board[0, 1];
```

배열의 크기는 `GetLength()` 메서드로 확인합니다.
- `board.GetLength(0)`: 행의 개수
- `board.GetLength(1)`: 열의 개수

전체 순회는 보통 중첩 `for` 문을 사용합니다.

```csharp
int[,] scores = {
    { 80, 90, 100 },
    { 70, 85, 95 }
};

for (int i = 0; i < scores.GetLength(0); i++)
{
    for (int j = 0; j < scores.GetLength(1); j++)
    {
        Console.Write($"{scores[i, j]} ");
    }
    Console.WriteLine();
}
```

### 4.2 가변 배열 (int[][])
`int[][]`는 배열 안에 배열이 들어가는 가변 배열(Jagged Array)로, 행마다 열의 길이가 다를 수 있습니다.

```csharp
int[][] jagged = new int[3][];
```

> [!TIP]
> `int[,]`은 모든 행의 열 크기가 고정된 직사각형(Rectangular) 형태이고, `int[][]`는 행마다 길이가 다를 수 있는 가변 배열입니다. 격자처럼 크기가 균일하면 `int[,]`, 행마다 크기가 달라질 수 있으면 `int[][]`를 사용합니다.
