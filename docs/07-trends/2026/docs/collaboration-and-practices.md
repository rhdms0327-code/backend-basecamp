> 2026년 10월 기준 국내 IT 기업이 쓰는 협업 도구(Jira·Notion·Git 등)와, 기술력 있는 회사들이 공통으로 갖춘 개발 문화를 정리합니다.

## 한 줄 요약

문서는 **Notion**이 사실상 표준에 가까워졌고, 이슈 관리는 중대형 개발 조직에서 **Jira**, 속도를 중시하는 개발 조직에서 **Linear**가 늘고 있습니다. 도구보다 더 큰 차이는 **코드 리뷰·설계 문서·장애 회고 같은 일하는 방식**에서 납니다.

---

## 협업 도구 현황

| 용도 | 2026 국내 현황 | 시니어가 할 줄 알아야 하는 것 |
| :--- | :--- | :--- |
| 이슈·일정 관리 | 50인 이상 개발 조직은 **Jira**. 개발 중심 조직은 **Linear**가 증가 | 작업 쪼개기(Epic → Story → Sub-task), JQL 검색, 스프린트 보드 운영 |
| 문서·위키 | **Notion**이 대세(토스·당근·오늘의집 등). 대기업·게임사·Atlassian 생태계는 **Confluence** | 설계 문서, ADR(설계 결정 기록), 장애 회고 템플릿 작성 |
| 코드 저장소 | **GitHub**이 가장 많음. 사내 설치형은 **GitLab**, Atlassian 생태계는 Bitbucket | PR 리뷰, 브랜치 보호 규칙, CODEOWNERS(파일별 리뷰 담당자) |
| 메신저 | Slack이 대부분. 카카오워크·네이버웍스·Teams | 장애 알림 채널 운영 |
| 디자인 협업 | Figma | 화면 기획서를 보고 API 설계하기 |

### 도구 선택 시 참고

- **Jira**: 정교한 관리가 가능하지만 학습 곡선이 높고 비싼 편이라는 평가가 있습니다. 도입 목적과 실제 사용 방식이 달라 폐지한 스타트업 사례도 공유된 바 있습니다.
- **Linear**: Jira의 복잡한 설정에 지친 개발팀 사이에서 호평을 받고 있습니다.
- **Notion**: 문서·위키와 전사 공용 도구로 쓰입니다. 국내 사용자·도입 기업 수치는 Notion 측 주장을 인용한 것이라 독립 검증이 필요합니다.

## 일하는 방식 — 기술력 있는 회사의 공통점

| 관행 | 내용 |
| :--- | :--- |
| **코드 리뷰** | 모든 코드가 PR로 들어가고 1~2명이 승인해야 병합합니다. 리뷰 코멘트를 잘 쓰는 것도 역량으로 봅니다 |
| **브랜치 전략** | Git Flow에서 GitHub Flow나 트렁크 기반 개발로 넘어가는 추세입니다. 커밋 메시지는 Conventional Commits 형식을 많이 씁니다 |
| **설계 문서** | 구현 전에 Design Doc이나 RFC를 쓰고 리뷰합니다. 결정 사항은 ADR로 남깁니다 |
| **애자일** | 2주 스프린트, 데일리 스탠드업, 회고, 스토리 포인트 추정 |
| **장애 대응** | 온콜 당번, 장애 등급 기준, 책임을 묻지 않는 회고(Blameless Postmortem) |
| **측정** | DORA 지표(배포 빈도, 변경 리드타임, 장애율, 복구 시간), SLO |
| **지식 공유** | 기술 블로그, 사내 세미나, 신규 입사자 온보딩 문서 |
| **리딩** | 주니어 멘토링, 1on1, 기술 부채 우선순위를 정해 PM과 협상 |
| 🆕 **AI 도구 운영** | 회사가 보안 승인한 AI 도구만 사용, 팀 단위 AI 사용 규칙 수립, AI가 생성한 코드 리뷰 ([AI 코딩 도구 도입 현황](./ai-coding-tools.md)) |

> 위 관행은 특정 통계가 아니라 국내외 기술 조직에서 일반적으로 쓰이는 방식을 정리한 것입니다.

---

## 레거시 환경에서 먼저 시작해볼 수 있는 것

도구를 바꿀 권한이 없어도 바로 연습할 수 있는 것들입니다.

1. **Jira 작업 쪼개기** — 큰 요청을 Story·Sub-task로 나눠 등록
2. **설계 문서·ADR** — 구현 전에 "왜 이렇게 하는가"를 1페이지로 남기기
3. **장애 회고** — 사람이 아니라 원인과 재발 방지책 중심으로 기록
4. **개인 프로젝트에서** — GitHub PR 기반 작업, Conventional Commits, CI 자동 테스트
