> OPIc은 질문을 듣고 말로 녹음하는 약 40분짜리 시험이며, 사전 설문에서 고른 주제로 문제가 나옵니다. 시험 구조를 먼저 이해하고, 문제 유형마다 "도입 → 본론 → 마무리" 틀을 정해 두면 내용만 즉석에서 채우면 됩니다.

---

## 한눈에 보기

| 구분 | 핵심 |
| :--- | :--- |
| 형식 | 컴퓨터 화면에서 질문을 듣고 말로 녹음, 1:1 인터뷰 방식 |
| 시간 | 40분 (오리엔테이션 포함 약 60분) |
| 문항 | 12~15문항, 난이도에 따라 달라짐 |
| 평가 | 전체 답변을 종합하는 전반적 평가(Holistic) |
| 성적 | 응시일로부터 약 5일 후 발표 |

---

## 1. 시험 구조

### 진행 순서

| 단계 | 이름 | 하는 일 |
| :--- | :--- | :--- |
| 1 | Background Survey | 직업, 거주, 여가·취미·운동·휴가 활동을 선택. 이 선택이 출제 주제가 됨 |
| 2 | Self Assessment | 난이도(1~6단계) 선택 |
| 3 | Pre-Test Setup | 마이크와 음량 점검 |
| 4 | Sample Question | 화면 구성, 청취와 답변 방법 연습 |
| 5 | 1st Session | 개인 맞춤형 문항 약 7문항 |
| 6 | 난이도 재조정 | 쉬운 / 비슷한 / 어려운 질문 중 선택 |
| 7 | 2nd Session | 개인 맞춤형 문항 약 5~8문항 |

- 질문은 **2회까지 들을 수 있고**, 문항별 **답변 시간 제한은 없습니다**.
- 진행 화면은 [공식 샘플 테스트 체험 가이드](./sample-test-guide.md)에서 캡처와 함께 볼 수 있습니다.

### 설문 선택 조건

| 분류 | 조건 |
| :--- | :--- |
| 여가 활동 | 2개 이상 |
| 취미·관심사 | 1개 이상 |
| 운동 | 1개 이상 |
| 휴가·출장 | 1개 이상 |
| 네 분류 합계 | 12개 이상 |

실제로 해본 활동 위주로 고르는 것이 답변을 만들기 쉽습니다. 자세한 선택 방법은 [설문 주제 선정 가이드](./survey-topic-guide.md)를 참고합니다.

### 채점 기준

| 평가 영역 | 의미 |
| :--- | :--- |
| Function | 묘사, 서술, 의견 제시 등 과제를 수행하는 능력 |
| Accuracy | 문법, 어휘, 발음의 정확도 |
| Content / Context | 주제와 상황에 맞는 내용 |
| Text Type | 단어, 문장, 문단 등 답변의 길이와 구성 |

> [!TIP]
> 정확도보다 **끊기지 않고 문단 단위로 말하는 것**이 더 큰 차이를 만듭니다. 한 문장으로 끝내지 않고 이유와 예시를 붙입니다.

## 2. 문제 유형별 답변 틀

문제를 듣고 어떤 유형인지 먼저 판단한 뒤, 아래 틀에 내용을 채웁니다.

| 유형 | 틀 | 주의 |
| :--- | :--- | :--- |
| 자기소개 | 이름·직업 → 하는 일 → 취미/성격 → 마무리 | 첫 문제이므로 자연스럽게 외워 두기 |
| 묘사 | 어디/무엇 → 특징 3가지 → 느낌 | 현재형 유지 |
| 루틴 | 언제/어떻게 → 순서(first, then, after that) → 이유 | 구체적 예시 한 가지 |
| 과거 경험 | 배경 → 사건 → 문제 → 해결 → 느낀 점 | 과거 시제를 끝까지 유지 |
| 롤플레이 | 질문 3~4개 → 상황 설명 → 대안 2개 제시 | 질문 형식(Could you tell me...?) 연습 |
| 비교 | 과거 vs 현재, A vs B → 차이 2~3개 → 내 생각 | 연결어(while, whereas) |
| 이슈 | 주장 → 이유 2개 → 예시 → 정리 | 의견을 먼저 말하기 |

### 가장 중요한 유형: 과거 경험

시간 순서가 있는 스토리를 끝까지 말할 수 있는지가 상위 등급을 가릅니다.

1. **배경**: 언제, 어디서, 누구와
2. **사건**: 무슨 일이 있었는지
3. **문제**: 가장 힘들었거나 예상 밖이었던 점
4. **해결**: 어떻게 해결했는지
5. **느낀 점**: 지금 돌아보며 배운 것

---

## 3. 막힐 때 쓸 연결 표현

| 상황 | 표현 |
| :--- | :--- |
| 생각할 시간이 필요할 때 | Well, let me think for a moment... |
| 말을 바꿔 설명할 때 | What I mean is... |
| 솔직하게 말할 때 | To be honest, ... |
| 과거를 돌아볼 때 | Looking back, ... |

---

## 4. 준비 전략 요약

- **통암기 금지**: 틀만 외우고 내용은 즉석에서 채웁니다.
- **소재 돌려쓰기**: 소재 5~6개를 준비해 어떤 주제 질문에도 끼워 맞춥니다.
- **답변 길이**: 한 문제 1분 30초~2분을 목표로 합니다.
- **자가진단 난이도**: 목표 등급에 맞춰 선택합니다. 상위 등급을 노린다면 6단계입니다.
