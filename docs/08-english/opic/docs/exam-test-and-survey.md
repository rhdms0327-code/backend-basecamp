## 2. 설문 주제 선정

선택 조건과 고르는 기준은 [설문 주제 선정 가이드](./survey-topic-guide.md)를 참고합니다.

### 선택 결과

#### 직업·학생·거주

| 문항 | 선택 |
| :--- | :--- |
| 종사 분야 | 사업/회사 |
| 직업 여부 | 예 |
| 근무 기간 | 첫 직장, 2개월 이상 |
| 관리직 여부 | 예(부하직원 관리) |
| 학생 여부 | 아니요 |
| 최근 수강한 강의 | 수강 후 5년 이상 지남 |
| 거주 | 가족과 함께 주택/아파트에 거주 |

#### 여가·취미·운동·휴가

| 분류 | 선택 항목 | 개수 |
| :--- | :--- | :--- |
| 여가 활동 | 박물관 가기, 공원 가기, 주거 개선, 캠핑하기 | 4 |
| 취미·관심사 | 아이에게 책 읽어 주기, 애완동물 기르기 | 2 |
| 운동 | 하이킹/트레킹, 헬스, 조깅 | 3 |
| 휴가·출장 | 해외 출장, 국내 여행, 해외 여행 | 3 |
| **합계** |  | **12** |

### 선택 과정

1. **12개 채우기가 가장 어려웠다**: 취미가 많지 않아 분류별로 고를 항목이 적었습니다.
2. **기준을 "요즘 실제로 하는 것"으로 잡았다**: 취미를 새로 만들기보다, 지금 생활(육아, 가족 중심)에서 하는 활동을 골랐습니다.
3. **여가·취미는 가족 활동 위주**: 박물관·공원·캠핑, 책 읽어 주기, 반려동물 돌보기처럼 아이와 함께하는 활동이 중심입니다.
4. **운동과 휴가는 경험이 있는 것**: 하이킹/헬스, 그리고 해외 출장과 국내·해외 여행처럼 과거 경험으로 이야기할 거리가 있는 항목을 골랐습니다.
5. **남은 과제**: 항목마다 쓸 소재를 정리합니다.

### 항목별 활용 방향

| 분류 | 선택 항목 | 이야기할 수 있는 방향 |
| :--- | :--- | :--- |
| 직업 | 사업/회사, 관리직 | 하는 일, 팀 관리, 힘들었던 일과 해결 |
| 거주 | 가족과 거주 | 집 묘사, 하루 루틴, 주거 개선 경험 |
| 여가 | 박물관, 공원, 캠핑 | 최근 다녀온 일, 특별했던 날, 비교 |
| 취미 | 책 읽어 주기, 반려동물 | 루틴, 시작한 계기, 변화 |
| 운동 | 하이킹, 헬스, 조깅 | 시작 계기, 기억에 남는 경험, 과거 vs 현재 |
| 휴가·출장 | 해외 출장, 국내/해외 여행 | 과거 경험 스토리의 핵심 소재 |

소재는 [설문 주제와 스토리 소재 뱅크](./story-bank.md)에 "상황 → 문제 → 해결 → 느낀 점" 순서로 정리합니다.

## 3. 소재 정리

질문에 답하면서 정리한 소재입니다. 영어 답변은 "상황 → 문제 → 해결 → 느낀 점" 순서로 이어 말합니다. 개인정보와 민감한 내용은 제외하고 일반화해 적었습니다.

### 직업

| 질문 | 답변 정리 |
| :--- | :--- |
| 하는 일을 한 문장으로 설명하면? | 백엔드 개발자. 비개발자에게도 "사용자가 보는 화면 뒤에서 데이터를 저장하고 처리하는 서버를 만드는 일"로 설명하고, 어떤 서비스인지 함께 말한다 |
| 관리하면서 가장 힘들었던 일은? | 이전에 내 설명이 길고 지시가 명확하지 않아 팀원이 이해하기 어려웠던 경험 |
| 어떻게 해결했나? | 가이드 문서를 AI로 쉽게 정리해 작성하고, 채팅 텍스트로 남겨 이력을 관리 |
| 결과와 느낀 점은? | 오해와 갈등이 줄었고, 설명을 기록으로 남기는 방식이 소통에 도움이 됨 |

### 거주

| 질문 | 답변 정리 |
| :--- | :--- |
| 사는 곳 소개 | 가족과 함께 사는 아파트 |
| 집을 바꾼 경험(주거 개선) | 오래된 집이라 어린 자녀와 살기 위해 전체 인테리어 공사를 크게 진행 |
| 공사 후 어려웠던 점 | 페인트 냄새, 새 가구 냄새, 청소 문제 |
| 어떻게 해결했나 | 꼼꼼히 청소하고 공기청정기를 구매 |
| 느낀 점 | 아이가 어릴 때는 집 환경이 가장 중요해서 준비와 사후 관리 모두 필요하다고 느낌 |

### 여가 활동

| 항목 | 질문 | 답변 정리 |
| :--- | :--- | :--- |
| 캠핑(소풍) | 어떻게 즐기나? | 아이가 생긴 뒤로는 캠핑보다 가벼운 소풍을 간다. 아이가 좋아하는 봄·가을에 가고, 날씨 확인, 넉넉한 간식, 벌레 퇴치제를 챙긴다 |
| 캠핑(소풍) | 좋은 장소의 조건은? | 아이가 좋아하는 음식과 간식을 준비하고, 넓은 들판이 있어 아이가 마음껏 뛰어놀 수 있는 곳 |
| 박물관 | 어떤 곳을 가나? | 아이의 나이와 관심사에 맞는 곳 위주로 간다 |
| 박물관 | 최근에 다녀온 곳은? | 어린이 박물관. 체험할 거리가 많고 아이도 좋아했다. 입장료가 5천 원 정도로 저렴해 놀랐다 |
| 박물관 | 앞으로 계획은? | 아이를 위한 박물관이 생각보다 많아서 하나씩 모두 가 볼 계획 |
| 공원 | 어떻게 즐기나? | 박물관과 함께 아이와 나가는 주요 코스 (구체적인 장면은 추가 예정) |

### 취미·관심사

| 항목 | 질문 | 답변 정리 |
| :--- | :--- | :--- |
| 책 읽어 주기 | 언제, 어떻게? | 아이 머리를 말려 줄 때 옆 책장에서 아이가 직접 책을 가져온다. 주로 좋아하는 동물 책을 골라 설명을 들려준다 |
| 책 읽어 주기 | 어려웠던 점은? | 동물이 먹이를 잡아먹거나 사냥하는 장면을 어린아이에게 어떻게 설명해야 할지 당황스러울 때가 있다 |
| 반려동물 | 어떤 동물인가? | 작은 강아지. 아이가 태어나기 전부터 키우고 있다 |

### 운동

| 항목 | 질문 | 답변 정리 |
| :--- | :--- | :--- |
| 홈트 | 지금 꾸준히 하는 운동은? | 집에서 유튜브 영상을 보며 하는 홈트레이닝 |
| 하이킹 | 어떤 점이 좋았나? | 근처 산에 가는 것을 좋아했다. 혼자 생각을 정리할 수 있고 산 경치를 구경하는 것이 좋았다 |
| 헬스 | 어떻게 했나? | 아이가 생기기 전에는 다이어트를 위해 주기적으로 헬스를 했다. PT로 기구 사용법과 자세를 배운 뒤, 이후에는 앱으로 루틴만 관리했다 |
| 변화 | 아이가 생기기 전후 차이는? | 헬스장 중심이던 운동이 집에서 하는 홈트로 바뀌었다 |

### 휴가·출장

| 항목 | 질문 | 답변 정리 |
| :--- | :--- | :--- |
| 해외 출장 | 어디서 무엇을 했나? | 미국에서 한 달. 프로젝트 진행을 위해 우리 기술력과 커뮤니케이션 능력을 증명하는 자리였다 |
| 해외 출장 | 가장 힘들었던 순간은? | 커뮤니케이션 역할이 매우 중요해서 부담이 컸다 |
| 해외 출장 | 어떻게 해결했나? | 친화적이고 활발한 성격으로 현지 사람들과 친해져 미팅을 잘 이끌었다. 통역 때문에 회의가 길어져 상대가 피로해 보이자, AI 실시간 번역을 제안했다 |
| 해외 출장 | 결과는? | 기술 팀장들이 실시간으로 이해하고 번역된 답변만 하면 되어 미팅이 매끄럽게 진행됐다 |
| 해외 여행 | 가장 좋았던 여행은? | 대학 졸업 전 두 달간의 뉴욕 여행. 돈이 넉넉하지 않아 아끼며 다녔고(서브웨이 30cm 샌드위치로 하루 종일 먹기, 맥도날드 화장실 이용) 그 추억이 특별하다 |
| 해외 여행 | 힘들었던 여행은? | 베트남 다낭. 가격이 정해져 있지 않아 물건을 살 때마다 흥정해야 해서 스트레스를 받았다 |
| 해외 여행 | 돌아보며 느낀 점은? | 차이가 한국 돈으로 500원 정도라서, 상대가 부른 가격을 그냥 줘도 됐다고 생각한다 |
| 국내 여행 | 아이와 기억에 남는 여행은? | 아이와 처음으로 먼 곳으로 간 여행. 식당에서도 차에서도 아이가 힘들어하지 않아 걱정과 달리 순조로웠고, 앞으로 다른 여행도 갈 수 있겠다는 자신감이 생겼다 |

### 소재 한 줄 요약

| 분류 | 소재 |
| :--- | :--- |
| 직업 | 비개발자에게 백엔드 개발을 설명하기 / 팀 소통을 문서와 기록으로 개선한 경험 |
| 거주 | 어린 자녀를 위한 전체 인테리어 공사와 공사 후 환경 관리 |
| 여가 | 아이와 함께하는 소풍(준비물, 장소 조건) / 어린이 박물관 체험 |
| 취미 | 아이가 고른 동물 책 읽어 주기 / 아이가 태어나기 전후의 반려견 생활 |
| 운동 | 아이가 생기기 전후 운동 방식의 변화(헬스 → 홈트) / 혼자 산에 가서 생각을 정리하던 시간 |
