> 설문에서 고를 주제와, 어떤 질문에도 돌려쓸 수 있는 스토리 소재를 정리하는 문서입니다. 소재는 "상황 → 문제 → 해결 → 느낀 점"으로 채웁니다.

---

## 설문 주제 선택

| 분류 | 선택 기준 |
| :--- | :--- |
| 직업 | 실제 직무 |
| 여가 활동 | 평소 해본 활동 2개 이상 (네 분류 합계 12개 이상) |
| 취미 | 평소 즐기는 것 1개 이상 |
| 운동 | 1개 이상 |
| 휴가·출장 | 해외 여행, 해외 출장 등 경험이 있는 것 |

---

## 스토리 소재

| 소재 유형 | 쓰기 좋은 질문 | 상황 → 문제 → 해결 → 느낀 점 |
| :--- | :--- | :--- |
| 해외 출장·업무 경험 | 출장, 직업, 문제 해결, 이슈 | |
| 해외 거주·학교 경험 | 어린 시절, 비교, 일상의 변화 | |
| 장기 체류 경험 | 해외 여행, 기억에 남는 경험, 힘들었던 일 | |
| 반복해서 간 여행 | 여행 루틴, 최근 여행, 여행 비교 | |
| 생활의 변화 | 비교(과거 vs 현재), 루틴 | |
| 업무에서 힘들었던 일 | 직업, 문제 해결, 이슈 | |
