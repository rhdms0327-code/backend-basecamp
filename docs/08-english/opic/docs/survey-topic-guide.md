> 시험 첫 단계인 Background Survey에서 고른 항목이 곧 출제 주제입니다. 선택 조건과 고르는 기준, 정리 방법을 안내합니다.

---

## 1. 설문이 중요한 이유

- 시험은 Background Survey → Self Assessment 순서로 시작하고, **설문에서 고른 항목으로 문제가 나옵니다.**
- 같은 영어 실력이라도 **답할 내용이 있는 주제**를 고르면 답변이 길고 구체적으로 나옵니다.
- 따라서 설문 선택은 시험 전에 정해 두고, 선택한 항목마다 답변 소재를 미리 준비합니다.

---

## 2. 선택 항목과 조건

설문은 아래 순서로 진행됩니다. 여가·취미·운동·휴가는 분류별 최소 개수가 있고, **네 분류를 합쳐 12개 이상**을 골라야 합니다.

| 단계 | 분류 | 조건 |
| :--- | :--- | :--- |
| 1 | 직업(분야, 근무 기간, 관리직 여부) | 각 1개 |
| 2 | 학생 여부, 최근 수강 | 각 1개 |
| 3 | 거주 형태 | 1개 |
| 4 | 여가 활동 | 2개 이상 |
| 5 | 취미·관심사 | 1개 이상 |
| 6 | 운동 | 1개 이상 |
| 7 | 휴가·출장 경험 | 1개 이상 |
| - | 4~7 합계 | **12개 이상** |

> [!NOTE]
> 항목 이름과 개수 표기는 시험 회차에 따라 다를 수 있습니다. 공식 샘플 테스트의 설문 화면에서 실제 항목을 확인하고 대조합니다. 체험 방법은 [공식 샘플 테스트 체험 가이드](./sample-test-guide.md)를 참고합니다.

---

## 3. 고르는 기준

| 기준 | 설명 |
| :--- | :--- |
| 해본 활동 위주 | 실제 경험이 있어야 과거 경험 문제에도 이어서 말할 수 있음 |
| 이야기가 되는 항목 | "언제, 어디서, 무슨 일이 있었는지"를 3문장 이상 말할 수 있는 것 |
| 소재를 겹쳐 쓸 수 있는 항목 | 하나의 경험(여행 등)이 여러 주제 질문에 쓰이도록 |
| 억지로 고르지 않기 | 말할 거리가 없는 항목은 질문이 나왔을 때 막힘 |

---

## 4. 정리 방법

설문 항목을 정한 뒤 아래 표로 정리하고, 항목마다 쓸 소재를 한 줄로 적어 둡니다.

| 분류 | 선택한 항목 | 쓸 소재(한 줄) |
| :--- | :--- | :--- |
| 직업 |  |  |
| 거주 |  |  |
| 여가 활동 (2개 이상) |  |  |
| 취미·관심사 (1개 이상) |  |  |
| 운동 (1개 이상) |  |  |
| 휴가·출장 (1개 이상) |  |  |

소재는 [설문 주제와 스토리 소재 뱅크](./story-bank.md)에 "상황 → 문제 → 해결 → 느낀 점" 순서로 정리합니다.

---

## 5. 확정 체크리스트

- [ ] 여가·취미·운동·휴가 분류별 최소 개수를 채웠다
- [ ] 네 분류 합계가 12개 이상이다
- [ ] 선택한 항목 모두 해본 경험이 있다
- [ ] 항목마다 쓸 소재를 한 줄로 적었다
- [ ] 샘플 체험 화면의 항목 이름과 대조했다
